# 接触失效感知的手指子集选择

本仓库对应论文 **Contact-Failure-Aware Finger-Subset Selection for Budget-Constrained Dexterous Grasp Refinement**，依据手稿与补充材料编写。

这是根据论文整理的参考实现，不是原实验源代码的历史归档。已实现网络、损失、子集策略、数据处理、训练、评估控制和统计流程；原始数据、训练权重、仿真资产和针对实际 GraspADMM 工程的适配器未随文档提供，因此没有宣称已经复现论文实验数值。

## 使用顺序

1. 按英文 README 安装 Python 3.12 环境和依赖。
2. 提供原始物体、Shadow Hand、接触链接要求、执行器分组、关节到执行器映射和完整仿真快照。
3. 按 `docs/backend_integration.md` 实现本地适配器，连接真实 GraspADMM。`my_adapter:create_backend` 是文档中的接入示例名称，并非已附带的模块。
4. 按物体划分训练、验证、测试集，生成标签，并运行数据审查。
5. 训练完整方法和三种消融设置，分别评估各训练种子与时间预算。
6. 使用汇总脚本生成统计表；使用绘图脚本从实际日志生成图片。

完整命令见 [英文 README](README.md)。论文与代码对应关系见 [方法映射](docs/method_mapping.md)，数据文件规范见 [数据格式](docs/data_schema.md)。

## 关键实现约定

- 位顺序为拇指、食指、中指、无名指、小指；子集按整数 1–31 排序。
- 未选择手指的执行器目标不变，手指仍可受接触力移动；不能把未选择手指的物理运动锁死。
- 每个子集从同一初始状态独立优化，目标变化约束在每次手部更新时执行。
- 人工修正力在优化结束后清除，经过 0.1 秒静置后保存状态；构型偏差在验证扰动前测量。
- 物理验证包含六个方向；每个方向恢复同一扰动后状态，关闭内置重力，在物体质心施加大小为质量乘重力加速度的力。
- 在线计时覆盖诊断、特征、推理、优化、状态恢复、静置和验证。超过时限的结果不接受。
- 最终成功率使用另外五次独立验证；构型偏差和手指数按在线接受集合统计；耗时按全部输入统计。
- 缺失偏差保存为 NaN，未执行方向保存为 -1；不会把缺失数据假装为观测结果。

论文没有明确给出的 MLP 细节、具体种子数值、特征聚合布局和静置阈值等，已在方法映射和代码注释中注明为参考实现选择，避免与原实验配置混淆。
